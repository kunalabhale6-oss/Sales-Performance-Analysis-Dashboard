# 📊 Sales Performance Analysis Dashboard | Tableau

## 📌 Project Overview

How can sales data help businesses understand performance and make better decisions?

This project features an interactive **Sales Dashboard for 2020**, developed using **Tableau**, to analyze sales performance, profitability, product subcategories, and trends over time.

The dashboard transforms sales data into meaningful visual insights, helping identify high-performing products, profit and loss patterns, and changes in business performance.

## 🎯 Project Objectives

- Analyze overall sales, profit, and quantity sold.
- Compare sales performance across product subcategories.
- Identify profitable and loss-making product categories.
- Explore monthly sales and profit trends.
- Highlight the highest and lowest performing months.
- Compare current-year sales with previous-year performance.
- Build an interactive dashboard for business performance analysis.

## 📈 Key Performance Indicators (KPIs)

- **Total Sales:** $484K
- **Total Profit:** $50K
- **Total Quantity Sold:** 8K

## 📊 Dashboard Features

### 1. Sales Overview
Displays key performance indicators for total sales, profit, and quantity, along with monthly trends and highest/lowest month indicators.

### 2. Sales & Profit by Subcategory
Compares sales and profit across product subcategories such as Phones, Chairs, Machines, Storage, Tables, Binders, and Accessories.

### 3. Profit & Loss Analysis
Highlights profitable and loss-making subcategories to understand product-level performance.

### 4. Sales & Profit Trends Over Time
Visualizes sales and profit trends throughout the year, including comparisons against average performance.

### 5. Year-over-Year Comparison
Provides a comparison of 2020 sales with the previous year's performance.

### 6. Interactive Dashboard
Includes filters and interactive visual elements to explore sales data dynamically.
